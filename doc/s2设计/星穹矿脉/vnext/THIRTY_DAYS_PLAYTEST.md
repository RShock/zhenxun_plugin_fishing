# 星穹矿脉三十天试玩

## 边界

本轮接续用户认可的前十天，追加两个十天。唯一资源仍为矿币，首星尚未挖穿，不提前发放重生资源。新增 23 项活动工程，其中启用原有储备 10 项、新增定义 13 项；合计 43 项活动工程，另有 3 项行星储备。没有每日购买硬上限，没有按现实关页时间补算。

## 两段建设

- D11-D20：完成电气矿网，推进地震回声、脉冲储能、光谱选矿，再进入压力换能、矿网拓扑、热回收、能源级联和闭环冷却。收入与钻进有所分工，早期矿道、矿工、动量和自动线继续参与新联动。
- D21-D30：深压蓄能衔接弱点矩阵、路程压缩与引力透镜，再加入奇点班组、量子裂隙、真空能流、量子分选、潮汐钻探和星核同步。溢出暴击率在弱点系统中重新有用途。
- 日期只是作者侧标定目标，运行时仍按深度、前置科技、自动线数量与矿币解锁。每日一次参考进入现代为 D15 13:10，未来为 D22 13:00，不是锁定时间。

## 新联动公式

`e` 表示同类效果的等级加权和，其他量为对应乘区值；每项作用域与共享数据一致。

| 联动 | 公式 | 作用 |
|---|---|---|
| 矿网拓扑 | `1 + e.network * sqrt(parallel * cats)` | 收入、深度 |
| 热量回收 | `1 + e.heat * (momentum + log10(speed))` | 收入 |
| 能源级联 | 各有活动科技的时代依次相乘 `1 + e.cascade * 已自动化数 / 活动科技数` | 收入、深度 |
| 弱点标定 | `1 + e.precision * fragility * critical * (1 + max(0, e.crit_chance - 0.65))` | 收入、深度 |
| 路程压缩 | `1 + e.compression * sqrt(penetration * pressure)` | 深度 |
| 引力透镜 | `1 + e.lens * log10(1 + depth) / 10 * compression` | 深度 |

地层压力与工艺多样性也在本段启用，但沿用既有公式。六项新公式均有逐级增益与联动回归，活动科技引用未知效果会直接报错，不能只写说明却没有实际收益。

后续增加时代内科技会改变能源级联的分母，必须检查旧档产能变化。固定基准日程只用于离线调参，不能代替不同策略的独立审计。

## 工具与风险

- `calibrate_thirty_days.mjs` 用每日一次参考轨迹拟合固定价格和深度；显式 `--write` 才保存。调参后必须运行 `s2_thirty_days.py --matrix --output` 和两端测试，不能只相信标定输出。
- `s2_thirty_days.py` 检查不同科技首购空档、买到买不起、数值有限、余额非负、时代到达、机会峰值及 Python/JS 三十天逐日与事件一致；失败须以非零退出，报告默认不写文件。
- 旧 D30 爆星、D45 重生断言仍跳过，因为相应功能尚未实现。当前三十天测试不能证明 60/120 天已平衡，也不穷尽所有策略。
- 完全托管仍会在未来里程碑落后约四天；指数增长使同日深度差很大，不能用“都进未来”掩盖。之后应继续比较达到相同内容所需时间，观察每天一次玩家是否感到被高频玩家拉开过多。
- 后期多数日子是调试 2 级、助手夜里补 1 级；这保证轻量，但节奏可能略重复。本轮优先稳定联动和操作量，后续可根据试玩增加少量有意义的选择，不增加强制上线频率。
