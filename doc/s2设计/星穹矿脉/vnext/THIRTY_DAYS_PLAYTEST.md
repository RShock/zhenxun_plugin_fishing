# 星穹矿脉三十天试玩

## 边界

内容版本 `thirty-day-eras-1`，保留用户认可的前十天经济，重做后两个十天的设备换代。唯一资源仍为矿币，共 43 项活动科技、3 项行星储备。首星尚未挖穿，不提前发放重生资源；没有每日购买硬上限，没有按现实关页时间补算。

## 时代与设备

- 原始、工业、电气、计算机、未来时代依次推进，以手工矿镐、炸药、电动矿车、数控钻台、量子钻头等设备体现变化。
- D11-D20：补齐过量穿透、电动矿车、蓄能飞轮、电磁分选机，再进入数控钻台、深井运输带、地质扫描器、智能分选机、液压支护网、矿渣回收站与自主地质探针。
- D21-D30：深压钻头衔接量子钻头、多层矿井、预测调度、星门运输、无人机矿群、材料重构、全自动矿场、量子分选仓、行星钻头与量子调度。
- 旧设备达到本代上限后停止采购，贡献保留；新设备重新调试并以更高系数接棒，不要求玩家学习新的联动公式。
- 日期只是作者侧标定目标，运行时仍按深度、前置科技、自动线数量与矿币解锁。每日一次参考进入计算机时代为 D15 13:10，未来为 D22 13:00，不是日期锁。

## 效果与标定

删除压力、矿网、热回收、工艺多样性、级联、弱点、压缩、透镜的活动公式。当前 15 个活动乘区、2 个行星储备乘区；后期设备复用既有作用域。

| 类型 | 计算方式 | 例子 |
|---|---|---|
| 同乘区线性设备 | `1 + sum(每级系数 * 等级)` | 运输带增加并行矿脉，分选机增加收入 |
| 速度设备 | 各设备的 `(1 + 每级系数)^等级` 相乘 | 数控钻台、量子钻头 |
| 收入与深度分工 | 收入设备不改变钻进，深度设备不改变收入 | 电磁分选机、深压钻头 |
| 既有自动化联动 | 班次接力与科技共振沿用自动线数量公式 | 自动换班协议、量子调度 |

同乘区后期系数必须考虑旧设备积累造成的稀释，不能只涨价格。新设备每一级都验证正收益与作用域隔离；速度独立复乘、同乘区相加、旧设备封顶和时代双门槛均有回归测试。

价格与解锁深度由 `calibrate_thirty_days.mjs` 在作者侧拟合后固定写入共享数据。运行中不根据天数或当前收入动态改价。标定轨迹不是验收，另跑不同画像、seed 和路线。

## 工具与风险

- `calibrate_thirty_days.mjs` 用每日一次参考轨迹拟合固定价格和深度；显式 `--write` 才保存。调参后必须运行 `s2_thirty_days.py --matrix --output` 和两端测试，不能只相信标定输出。
- 独立 pytest 必须设置 `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1`，否则 nonebug 自动夹具会要求正式机器人环境；既有 `asyncio_mode` 配置警告不影响本次测试。
- `s2_thirty_days.py` 检查不同科技首购空档、买到买不起、数值有限、余额非负、时代到达、机会峰值及 Python/JS 三十天逐日与事件一致；失败须以非零退出，报告默认不写文件。
- 旧 D30 爆星、D45 重生断言仍跳过，因为相应功能尚未实现。当前三十天测试不能证明 60/120 天已平衡，也不穷尽所有策略。
- 完全托管仍会在未来里程碑落后约四天；指数增长使同日深度差很大，不能用“都进未来”掩盖。之后应继续比较达到相同内容所需时间，观察每天一次玩家是否感到被高频玩家拉开过多。
- 后期常见手动调试 2 级、助手夜里补 1 级，轻量但可能重复；下一轮优先打磨设备叙事与换代反馈，不增加强制上线频率。
- 继承的早期暴击率封顶为 0.65，两项相关设备满级合计 0.72，末级可能无边际收益。本轮保留前十天基线，不再用后期溢出暴击公式补偿；需在后续早期专项调整中处理。
