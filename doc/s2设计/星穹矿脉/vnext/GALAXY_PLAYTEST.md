# 银河航程验收

版本：`prestige-2`。本报告对应独立试玩原型，不代表正式活动数值已定稿。

## 经济语义

- 挖穿每颗星球获得核心；奖励为 `1 + floor((星球序号 - 1) / 5)`。
- 核心是购买永久科技的货币，余额和转生次数均不赠送产速。
- 行星开采引擎第一级花 1 核心，总倍率从 ×1 变成 ×2；第二级花 3 核心，总倍率从 ×2 变成 ×3，边际提升 50%。
- 七项永久科技分别加强全局产速、速度设备、收入设备、深度设备、综合设备与自动线联动。银河引擎的逐级翻倍同样必须付费购买。
- 每次启程清空全部本地科技、调试、自动线、矿币与深度。本地年龄重新计时；满级后的采矿仍然产出，不以满级代替通关。
- 首星必须手动启程；核心托管默认关闭，可以显式选择均衡低价或速度路线。

## 算法与边界

首星及第二、三颗星球保留原离散随机结算。第四颗起零调试门槛，使用确定性的期望产出与连续事件结算：

1. 模拟真正的价格、矿币、深度、前置科技和时代门槛，只在条件满足时购买。
2. 精确积分原有的本地年龄联动和钻进动量，跳转到下一次购买、解锁或挖穿事件，不逐秒或逐次挖矿。
3. 相同永久科技与起始条件复用完整航程；单纯积累核心不使缓存失效。途中手动买永久科技，从现有矿井状态重算剩余航程。
4. 批量使用核心奖励前缀和与二分查找，停在下一次可自动购买永久科技的星球；支付后重算，不用旧航程跨过强化点。
5. 保留残余航程、真实累计建设数、核心收支和最近 20 次航程，不为百万颗星球创建百万条记录。百万终局停止生产和启程。

网页直接调用同一个 `engine.js`，不另建 UI 经济引擎。Python 参考模型使用相同 JSON，独立实现连续积分与结算用于对拍。

## 自然开局回放

命令：`node doc/s2设计/星穹矿脉/vnext/s2_galaxy_replay.mjs --seed 42 --profile daily --route balanced`，从插件目录运行。可将 profile 改为 `absent`、route 改为 `speed` 或 `off`。

每天分 1200、240 分钟推进；daily 在 20:00 手动建设一次，absent 不手动建设。两者均在首星完成后的 20:00 授权首次启程并开启指定核心托管。这里的 absent 不是免除首次启程授权。下表为百万星球最后一颗的完成时刻，单位为自开局起的完整日，而非界面 D 编号。

|---|---:|---:|

| 7 | 130.291143 | 137.395309 |
| 42 | 130.207809 | 137.992532 |
| 99 | 131.207809 | 137.395309 |

Seed 42 每日一次、仅速度核心路线为 140.797668 日。均衡路线累计编译 67 个航程、22,311 个本地购买事件；速度路线为 35 个航程、11,655 个事件。不是模拟了一百万套升级。

**节奏限制：**目前绝大多数星球集中在后期很短的爆发段完成。测试证明能自然走通、选择有差异、算法不会逐星卡死，不证明后半段已经足够耐玩。后续应调整永久科技成本、强化幅度和阶段分布；不能用按日硬限、登录锁或免费转生倍率拖长时间。

## 正确性与性能

- JavaScript 共 53 项测试通过，包括旧十天 80 画像、前三十天精确回归、末级之后真实采矿、逐星与批量对照、分段推进、刷新恢复、途中强化、自动核心购买边界与旧存档迁移。
- Python 四套测试共 63 项通过，覆盖首段、三十天、转生与连续航程；其中 9 项连续航程测试包含从零 daily/absent 百万星球与 JS 对拍。独立运行禁用插件自动加载，因此现有 `asyncio_mode` 配置产生一条未识别配置警告，不影响测试通过。
- 积分另用独立中点数值积分验证，不只让两个相同实现互相证明。
- 每个编译购买事件检查真实成本、深度、科技前置与付费等级；整数核心与等级要求精确守恒，浮点时间与产出采用容差。
- 合成的满永久科技场景，结算剩余约 98 万颗星球约 20–25 毫秒，只编译 1 个航程、333 个购买事件；单颗航程约 0.0032448 秒。这是性能压力测试，不是从零自然开局耗时。
- 五 seed 自然开局各路线在本机约 1.6–1.8 秒完成一次回放。墙钟性能受设备和并发任务影响，不作为固定用户承诺。

## 网页验收

使用 `?sandbox=1` 独立存档，不推进用户主存档。已检查旧转生版接续、免费倍率移除、关闭状态的核心托管、切换均衡路线、推进 1 秒、跨星球推进 30 天、刷新恢复与百万终局。桌面 1280×900、手机 390×844 检查科技商店布局，手机页面无横向溢出，矿井图片正常加载。

旧版迁移先备份再覆盖，保留现有核心和已购科技，不补发引擎等级。旧历史航程记录保留当时事实，不按新倍率倒算。当前版损坏存档不得被误当旧版自动修补。

范围仍限百万星球、双精度数值与本地模拟时间；尚未实现正式机器人接入、主游戏奖励、现实关页时间补算或超过安全整数范围的大数结算。
