# S2 星穹矿脉 vNext 数值与体验设计

> 状态：阶段一 D1～D10 已签收；D11 以后尚待分段校准。阶段二暂时冻结，未通过阶段一签收前不得继续扩展。

## 1. 设计目标

S2 是独立于钓鱼主世界的增量游戏。玩家从一把生锈矿镐开始，固定时间挖掘并获得锡矿、铜矿等材料，使用矿石精炼成矿币，购买更多升级，再把一颗星球挖穿。爆星会清空本地经济与本地科技，换来星球核心；核心购买永久科技，使下一颗星球更快。

当前只实现并审查第一个循环：

1. **单星球循环**：固定时长结算 → 获得矿物与矿币 → 批量升级 → 解锁七个时代和特殊科技 → 挖穿并重生。

核心科技购买已作为阶段一的重生边界保留，用于验证“下一颗星球更快”；无限星球数量、`10^308` 目标和最终通关奖励属于阶段二，当前不进入场景报告。

这里的“挖矿”是交互外壳。核心挑战是升级选择、重生规划和数量级增长，不做逐个矿点的步进事件。

## 2. 不可破坏的交互约束

| 约束 | 当前实现 |
|---|---|
| 时间推进 | 1 分钟固定步；每步计算深度、矿物、矿币和轻微扰动 |
| 每日升级消息 | 手动消息最多 3 条；一条消息可批量购买多个项目、多个等级 |
| 日内决策机会 | 活跃玩家每小时可查看；策略按真实购买后的观察时间、资源储备和剩余机会决定是否用消息，不绑定固定窗口 |
| 自动升级 | 某条本地升级达到 3 级后自动采购资格永久保留；重生后仍有效 |
| 猫矿工 | 每只猫复制一份本地基础挖掘数据；最多 12 只，雇佣 3 只猫时约为 4 倍工人产能 |
| 科技规模 | 124 条本地科技节点，29 条特殊科技效果；每条节点有独立名称、成本、上限、时代门槛和效果 |
| 重生 | 清空本地矿物、矿币、本地等级和当前深度；保留核心、永久科技、累计爆星数和自动资格 |
| 资源边界 | 矿物按时代承担配方门槛，矿币是本地主要消费货币，核心是重生货币；不接入旧钓鱼币、药水或 S1 |
| 随机性 | 使用固定 seed 的截断正态扰动；前十天仍固定 10 分钟步进，因此同一 seed 可重复，但不会把随机特殊科技强行折算成每小时必触发 |

每日限制只限制玩家发送的升级消息，不限制自动采购。这样 QQ 群里每天只需做三次规划，但达到 3 级后的升级不会要求玩家连发指令。

## 3. 本地资源与解锁曲线

矿物按深度提高稀有度：

| 材料 | 初始权重 | 用途 |
|---|---:|---|
| 锡矿 | 68% | 基础工程节点的材料门槛（基础时代每级约 500） |
| 铜矿 | 25% | 工业时代节点（每级约 50,000） |
| 紫晶 | 5.5% | 电力时代节点（每级约 80,000） |
| 金猫锭 | 1.4% | 现代与未来设备（每级约 50,000～200,000） |
| 虹核晶 | 0.1% | 未来、行星与异常科技的高阶门槛 |

权重在 12% 和 58% 深度处平滑转移，玩家会自然看到“锡矿 → 铜矿 → 紫晶 → 金猫锭 → 虹核晶”的图鉴式发现。

本地升级不是 12 条长条的改名版本，而是 124 个可单独购买的节点。基础主线仍采用线性单级效果，节点之间通过时代门槛、资源类型和自动化资格形成选择；特殊节点只做轻微延迟，不再用顺序前置把一个时代截断成前三项。

基础主线的单级效果包括：

- 矿镐：每级 `+0.35` 基础挖掘力，最多 100 级。
- 矿车：每级 `+0.04` 携带量，最多 100 级。
- 矿石精炼：每级 `+0.22` 矿币收益，最多 100 级。
- 洞穴勘探：每级 `+0.25` 推进效率，最多 100 级。
- 猫矿工：每级增加一名复制基础数据的工人，最多 12 只。
- 爆破镐、蒸汽矿车：工业时代各 40 级。
- 电动镐、电力车：电力时代各 40 级。
- 掘进机：现代时代 40 级。
- 微观量子挖掘：未来时代 30 级。
- 相对论效应：星球级 10 级；每次重生后已有该科技时，前 60 秒速度 `×100`。

七个时代各有 16 个节点：基础工程、工业时代、电力时代、现代时代、未来时代、行星时代和异常科技。异常科技节点包含相对论回响、真空涨落、因果回收、时间膨胀舱、奇点穿刺、熵减协议、多维猫爪、虚数矿脉、观测者偏置、宇宙弦牵引、反物质排渣、无穷压缩、星门装载、宇宙背景采样和终极挖掘许可等独立内容。

单级不直接给出一万倍，但基础、携带量、精炼、猫、时代设备和永久科技互相叠乘，后期仍会非常狂野。

## 4. 重生边界科技

| 科技 | 上限 | 效果 |
|---|---:|---|
| 行星之力 | 100 | 每级 `+1.00` 全局速度；第 1 级让下一轮速度翻倍 |
| 阶段跳过 | 20 | 每级减少 8% 星球深度需求，最低保留 2% |
| 核心勘探技术 | 50 | 每级每次爆星额外获得 1 个核心 |
| 宏观量子纠缠 | 40 | 每级在爆星时额外摧毁 25% 星球，按小数累计 |
| 全自动采购 | 1 | 所有本地升级都获得自动采购资格 |
| 核心量子加速 | 50 | 每级 `+1.50` 全局速度 |

核心升级也消耗手动升级消息；“3 条消息”是全局 QQ 交互约束，而不是只限制本地科技。阶段一场景会轮换购买这些科技，但不会把它们扩展成阶段二的无限外推系统。

## 5. 阶段体验基线

为了在开发机上逐步观察，阶段一默认使用 `11` 档，实际校准深度约为 `6×10^11`。它不是上线时的最终深度，只是让七个时代和首次重生能在有限模拟时间内被检查；`10^308` 属于阶段二，当前不参与阶段一场景。基础四项的初始价格为矿镐 `500`、矿车 `750`、精炼 `1100`、勘探 `1500` 矿币。自动采购每 10 分钟结算一次；活跃玩家每小时检查一次，但全天最多发送三条成功升级消息。通关天数只用于观测，不设置上线硬期限。

2026-08-07 的固定 `seed=42`、每小时检查策略观察到：

| 时间点 | 观察到的体验 |
|---|---|
| D1 | 01:00 首次升级矿镐 `+1`；全天手动数量包含 `+1` 和 `+2`，没有强行把项目冲到 3 级 |
| D2～D3 | 基础工程逐步解锁矿车、精炼、勘探和猫矿工；每小时可以查看，实际每天只发送三条升级消息 |
| D5 | 首次进入工业时代，爆破镐和蒸汽矿车开始成为新路线 |
| D10 | 仍处于工业时代，当前符合“D9 电力过快”的减速要求 |
| D13 | 首次进入电力时代，落在当前 D11～D14 方向内 |
| D19 | 首次进入现代时代；这只是当前结果，尚未签收后续时代节奏 |
| D20 | 触达 43/124 个本地节点，尚未发生首次重生 |

实际天数和节点日程不作为硬指标；科技出现的大致先后、消息限制、第一次重生的决策感和重生后明显加速才是要保留的体验。D1～D10 已签收：前十天自然混合 `+1/+2/+3`，直接 `+3` 每天最多一次，多数日期会把最后一条消息保留到中午以后；后续不能为了旧 D30/D45 测试而破坏这段曲线。

前十天验收命令为：

```powershell
.venv\Scripts\python.exe zhenxun/plugins/zhenxun_plugin_fishing/doc/s2设计/星穹矿脉/vnext/s2_first_ten_days.py --days 10 --seed 42
```

该序列默认生成每 60 分钟检查的主时间线，并同时审计每 3 小时和每天 3 次查看的画像；三者全天都最多发送三条成功升级消息。固定 seed=42 使路径可重复，同时保留随机扰动；完整结果写入 `FIRST_TEN_DAYS_TRACE.md`。`seed=1、7、42、99、2026` 的三画像矩阵均保持 D10 未进入电力时代。

特殊科技节点在所属时代跨度内额外延后约 `3%` 开放，普通节点也分布在整个时代跨度中，而不是时代标签出现时一次全部解锁。这样相对论、量子隧穿、奇点收尾等效果不会在新工业阶段刚出现时就跳过整颗星球；跳跃型效果仍需到星球进度 `0.5%` 后才生效，避免前期曲线突然折断。

## 6. 阶段二冻结边界

旧原型保留了 `LogNumber` 和 `project_stage_two()` 作为未来实验入口，但阶段一场景不会调用它们。阶段二要等下面的阶段一条件全部满足后才恢复：

- 每个本地节点有独立效果，而不是只增加计数。
- 7 个时代均能在场景中解锁，124/124 节点均有购买记录。
- 29 个特殊科技均有可观察的触发或收益变化。
- 首次重生窗口在不同 seed 下仍处于可接受范围；完整游戏不设硬性通关天数。
- 主程序集成协议和存档格式已经确定。

## 7. 阶段一签收清单

1. 用至少 3 个 seed 重跑 D1～D45，确认首次爆星和节点覆盖稳定。
2. 检查猫、时代门槛、自动采购和特殊科技没有任何“字典存在但策略永远买不到”的节点。
3. 检查核心科技路线不会被行星之力单一路线永久垄断。
4. 阶段一签收后，才允许设计阶段二的 `10^308` 星球数量、核心数量级和 S3 奖励。
