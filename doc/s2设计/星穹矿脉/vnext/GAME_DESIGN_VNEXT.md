# S2 星穹矿脉 vNext 数值与体验设计

> 状态：第一轮命令行闭环模拟。这里的数字是可运行的基线，不是最终上线配置。

## 1. 设计目标

S2 是独立于钓鱼主世界的增量游戏。玩家从一把生锈矿镐开始，固定时间挖掘并获得锡矿、铜矿等材料，使用矿石精炼成矿币，购买更多升级，再把一颗星球挖穿。爆星会清空本地经济与本地科技，换来星球核心；核心购买永久科技，使下一颗星球更快。

两个循环分别是：

1. **单星球循环**：固定时长结算 → 获得矿物与矿币 → 批量升级 → 解锁工业、电力、现代、未来和星球级科技 → 挖穿。
2. **核心循环**：爆星 → 获得核心 → 购买行星之力、阶段跳过、核心勘探、宏观量子纠缠和自动采购 → 更快爆星 → 最终对无限星球数做对数外推。

这里的“挖矿”是交互外壳。核心挑战是升级选择、重生规划和数量级增长，不做逐个矿点的步进事件。

## 2. 不可破坏的交互约束

| 约束 | 当前实现 |
|---|---|
| 时间推进 | 1 分钟固定步；每步计算深度、矿物、矿币和轻微扰动 |
| 每日升级消息 | 手动消息最多 3 条；一条消息可批量购买多个项目、多个等级 |
| 自动升级 | 某条本地升级达到 3 级后自动采购资格永久保留；重生后仍有效 |
| 猫矿工 | 每只猫复制一份本地基础挖掘数据；最多 12 只，雇佣 3 只猫时约为 4 倍工人产能 |
| 重生 | 清空本地矿物、矿币、本地等级和当前深度；保留核心、永久科技、累计爆星数和自动资格 |
| 资源边界 | 矿物是收集和配方材料，矿币是本地主要消费货币，核心是重生货币；不接入旧钓鱼币、药水或 S1 |
| 随机性 | 固定 seed 可复现；矿物产量和深度各使用截断正态扰动，避免极端运气决定通关 |

每日限制只限制玩家发送的升级消息，不限制自动采购。这样 QQ 群里每天只需做三次规划，但达到 3 级后的升级不会要求玩家连发指令。

## 3. 本地资源与解锁曲线

矿物按深度提高稀有度：

| 材料 | 初始权重 | 用途 |
|---|---:|---|
| 锡矿 | 68% | 早期矿镐、矿车和基础精炼 |
| 铜矿 | 25% | 工业科技与中期设备 |
| 紫晶 | 5.5% | 电力时代设备 |
| 金猫锭 | 1.4% | 现代与未来设备 |
| 虹核晶 | 0.1% | 星球级科技、相对论效应 |

权重在 12% 和 58% 深度处平滑转移，玩家会自然看到“锡矿 → 铜矿 → 紫晶 → 金猫锭 → 虹核晶”的图鉴式发现。

本地升级的单级效果都是线性的：

- 矿镐：每级 `+0.35` 基础挖掘力，最多 100 级。
- 矿车：每级 `+0.20` 携带量，最多 100 级。
- 矿石精炼：每级 `+0.22` 矿币收益，最多 100 级。
- 洞穴勘探：每级 `+0.25` 推进效率，最多 100 级。
- 猫矿工：每级增加一名复制基础数据的工人，最多 12 只。
- 爆破镐、蒸汽矿车：工业时代各 40 级。
- 电动镐、电力车：电力时代各 40 级。
- 掘进机：现代时代 40 级。
- 微观量子挖掘：未来时代 30 级。
- 相对论效应：星球级 10 级；每次重生后已有该科技时，前 60 秒速度 `×100`。

单级不直接给出一万倍，但基础、携带量、精炼、猫、时代设备和永久科技互相叠乘，后期仍会非常狂野。

## 4. 核心永久科技

| 科技 | 上限 | 效果 |
|---|---:|---|
| 行星之力 | 100 | 每级 `+1.00` 全局速度；第 1 级让下一轮速度翻倍 |
| 阶段跳过 | 20 | 每级减少 8% 星球深度需求，最低保留 2% |
| 核心勘探技术 | 50 | 每级每次爆星额外获得 1 个核心 |
| 宏观量子纠缠 | 40 | 每级在爆星时额外摧毁 25% 星球，按小数累计 |
| 全自动采购 | 1 | 所有本地升级都获得自动采购资格 |
| 核心量子加速 | 50 | 每级 `+1.50` 全局速度 |

核心升级也消耗手动升级消息；“3 条消息”是全局 QQ 交互约束，而不是只限制本地科技。

## 5. 阶段体验基线

为了在开发机上逐步观察，模拟器的可玩目标设为 `10^9` 深度。它不是上线时的最终深度，只是让每个阶段能在几十天内被检查；换成 `10^308` 时应使用相同公式和对数外推，不得逐个循环。

首轮固定 seed=42 的预设策略观察到：

| 时间点 | 观察到的体验 |
|---|---|
| 第一天 | 无旧货币，先挖出锡矿和少量铜矿；当天没有可用升级消息，符合“先赚第一桶金” |
| 第二天 | 一条消息可同时升矿镐和矿车，另两条买精炼、勘探和第一只猫；达到 3 级的科技开始自动采购 |
| 第三天 | 基础四线与猫的自动化开始吞吐资源，玩家可以看到收入明显超过手动购买速度 |
| 第七天 | 工业前置达到深度门槛，爆破镐与蒸汽矿车出现；铜矿不再只是图鉴收藏 |
| 第十一天 | 电力设备开始解锁，单星球深度推进显著加速 |
| 第十五天 | 现代设备逐渐可买，资源从“够买一级”变为“等下一条消息批量买多级” |
| 第二十天 | 未来科技门槛接近，猫与多条时代线的叠加使速度进入数量级增长 |
| 第二十五天 | 深度接近地心；此时的限制主要是每日三条规划，而不是等待输入 |
| 第二十九天左右 | 首次爆星，清空本地资源并获得核心；行星之力让下一颗星球有明确的重生收益 |
| 第三十七至四十五天 | 多次重生后核心勘探、阶段跳过和自动采购开始取代手动规划，玩家主要检查爆星数量 |
| 后期 | 相对论的 60 秒爆发、宏观纠缠和稳定态外推负责“越玩越快”，直到达到二阶段通关阈值 |

实际天数不作为硬指标；科技出现顺序、消息限制、第一次重生的决策感和重生后明显加速才是要保留的体验。

补充方差检查：seed=`1`、`42`、`2026` 都在第 29 天首次爆星，第 35 天均达到 2 次爆星并购买 2 级行星之力。截断正态扰动目前只改变短期产量，不会把首次通关推离目标窗口。

## 6. 超大数处理

阶段二不保存“第几个星球”的普通整数。模拟器的 `LogNumber` 保存尾数和十进制指数，支持加法、乘法、比较和格式化；稳定态只记录：

```text
单星球分钟数 = 有效深度 / (8 × 稳定速度)
目标分钟数的 log10 = 目标星球数的 log10 + log10(单星球分钟数)
```

例如目标为 `10^308`，程序只输出 `10^311.xx` 分钟级别的估计，不会分配 `10^308` 个对象。批量外推前仍要保留前几十轮精确模拟，以便验证自动采购和核心消费没有逻辑错误。

## 7. 下一轮调整顺序

1. 用 3 个不同 seed 重跑 D1～D45，检查首次爆星是否稳定落在约 25～35 天。
2. 重点检查猫的价格、工业门槛和自动采购是否让“第二天有猫、第三天能感到自动化”成立。
3. 对核心科技做一次互斥策略比较：行星之力（稳态速度）、阶段跳过（缩短单轮）、核心勘探（加大永久投资）和纠缠（数量爆发）不能出现唯一正确解。
4. 数值确认后再接入主程序模型、指令 matcher、HTML 状态页，并同步编写浅显版 `help.html`；本轮不提前触碰这些文件。
