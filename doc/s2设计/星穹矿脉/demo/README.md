# 猫猫挖矿 Demo · S2 v4.2

## 玩法摘要

- 指令循环：挖矿 / 挖矿状态 / 结束挖矿；
- 挖穿即一阶无限，清除库存、等级、自动化、地层与本轮进度；
- 每次一阶固定获得 1 星核，只用于永久科技；
- 前三次完整手动重玩，之后依次解锁开局、升级、地层与一阶重置自动化；
- 二阶门槛为 `10^308`，禁止逐轮遍历；
- 永久科技固定后精确模拟一次完整一阶循环，再按 `精确前缀 + 单循环 × 剩余轮数` 批量外推；
- 长挂机矿产使用期望值与可复现、零均值、±2% 受控扰动。
