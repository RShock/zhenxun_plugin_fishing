# S2 · 猫猫挖矿（星穹矿脉）

> 状态：**v5 多系统升级 + 指数加速** · 网页 Demo 已测试通过
> **完全独立**：不消耗鱼竿，不读写钓鱼金币；无天气/鱼饵/UTR/乐园。

## 一句话

两个完整循环：**一阶段**挖穿一个星球（149 项局内升级驱动的增量游戏），**二阶段**挖穿无限星球（22 项永久升级驱动的指数加速，直达 10^308 奇点）。

## V5 核心设计

### 慢起步 + 多系统交叉

- 初始挖掘速度极慢（裸通需 50,000 日），必须购买升级才能推进
- 五条局内升级线交叉影响，按深度门控解锁

### 一阶段：单星挖掘（完整增量游戏）

| 升级线 | 项数 | 说明 |
|--------|------:|------|
| 钻头系统 | 8 | 每级 ×2 挖掘力，总 ×256 |
| 矿物等级 | 25×5 | 每级 ×2.04 产量，5 种矿物独立升级 |
| 深度引擎 | 6 | 每级 ×1.3 深度效率 |
| 自动化模块 | 5 | 按深度解锁自动购买升级 |
| 地层科技 | 5 | 特色加成（专精、共振、护盾等） |
| **合计** | **149** | |

### 二阶段：无限星球（永久升级驱动）

| 分类 | 项数 | 说明 |
|------|------:|------|
| 起步倍率 | 9 | 钻头继承、矿物继承、矿物共振 |
| 全局加速 | 6 | 全局效率 ×1.5、地心深度 −20% |
| 自动化保留 | 5 | 开局自带自动化模块 |
| 星核倍增 | 2 | 每次获得 2/3 星核 |
| **合计** | **22** | |

### 指数加速验证

实测各阶段每轮耗时（×100 模拟速度）：

| 永久升级 | 起步倍率 | 每轮耗时 |
|----------|------:|------|
| 无 | ×1 | ~1,200 日 |
| 钻头继承 I + 矿物继承 I | ×8 | ~400 日 |
| 钻头继承 III + 矿物继承 II + 全局加速 I + 深度压缩 I | ×499 | ~100 日 |
| 全部 22 项 | ~×10^6 | 稳定态批量外推至 10^308 |

## 定案约束

| 项 | 值 |
|----|----|
| 循环 | 挖矿 / 结束挖矿 / 挖矿状态 |
| 地心目标 | 深度 `1e8` 挖穿并重置 |
| 二阶门槛 | 累计 `10^308` 次一阶无限 |
| 深度门控 | 升级按深度百分比解锁（3%~90%） |
| 重置规则 | 库存、等级、钻头、引擎、自动化、地层科技全部清除；永久升级保留 |
| 稳定态外推 | 全部永久升级集齐后，精确采样一轮，批量外推剩余轮次 |

## 与旧版
